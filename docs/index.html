Features

Everything at a glance

Keep track of all your parallel Claude Code sessions without switching between terminal windows.

Dynamic Island

A floating pill at the top of your screen with an animated crab. Compact when idle, expands on click to reveal all sessions.

Ambient Glow

The island glows green while working, pulses orange when a session needs input, and flashes pink on errors.

Desktop Notifications

Get a native macOS notification with a sound when any Claude session needs your input or permission.

Tmux Navigation

Click any session to instantly focus its tmux pane. Selects the right window, pane, and activates your terminal.

Unique Crab Names

Each session is deterministically assigned a charming crab name like Pinchy, Clawdia, or Captain Claw.

Zero Config

One command installs everything: compiles the Swift app, copies hooks, and configures Claude Code settings.

Crab States

Meet the moods

Each crab visually reflects what its Claude session is doing right now.

Working

Orange crab with wiggling legs and sparkles. Claude is processing.

Needs Input

Red bouncing crab with "!" badge. Claude needs your attention.

Needs Permission

Orange bouncing crab with "!" badge. A tool needs your approval.

Idle

Gray crab with closed eyes and floating "z"s. Waiting for a prompt.

Error

Pink crab with an alert badge. An API error occurred.

Architecture

How it works

Claude Observer uses Claude Code's hook system to track session lifecycle events in real time.

1

Hook Events Fire

Claude Code triggers hooks on lifecycle events: session start/end, prompt submit, tool use, notifications, permission requests, and subagent activity.

2

Python Hook Writes State

The observer hook script receives event data via stdin and atomically writes a JSON file per session to ~/.claude-observer/sessions/.

3

Dynamic Island Polls

The floating panel polls the sessions directory every 2 seconds, reads the JSON files, and updates the island display with animated crabs and glow effects.

4

Notifications & Navigation

When a session needs attention, a native macOS notification fires. Clicking a session in the expanded island focuses its tmux pane.

Getting Started

Install in seconds

Requires macOS 12+, Xcode Command Line Tools, and Python 3.

1

Clone the repository

git clone https://github.com/svenliebig/claude-observer.git
cd claude-observer
2

Install

Compiles the Swift app, installs the hook script, and configures Claude Code hooks.

make install
3

Run

make run
# or directly:
~/.claude-observer/bin/claude-observer &

Stop

make stop

Uninstall

make uninstall

Tip: Add the binary to System Settings > General > Login Items for auto-start on login.
