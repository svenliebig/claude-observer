Features

Everything at a glance

Keep track of all your parallel Claude Code sessions without switching between terminal windows.

Animated Status Bar Crab

A pixel-art crab lives in your menu bar, with legs that wiggle when Claude is working and eyes that close when idle.

Session Dropdown

Click the crab to see all active sessions, each with its own crab name, working directory, and real-time status.

Desktop Notifications

Get a native macOS notification with a "ding" sound when any Claude session needs your input or permission.

Auto-Cleanup

Stale sessions from crashed or killed Claude processes are automatically detected and cleaned up.

Unique Crab Names

Each session is deterministically assigned a charming crab name like Pinchy, Clawdia, or Captain Claw.

Zero Config

One command installs everything: compiles the Swift app, copies hooks, and configures Claude Code settings.

Crab States

Meet the moods

Each crab visually reflects what its Claude session is doing right now.

Working

Orange crab with wiggling legs and sparkles. Claude is processing your request.

Needs Input

Red bouncing crab with "!" badge. Claude needs your attention right now.

Idle

Faded gray crab with closed eyes and floating "z"s. Waiting for your next prompt.

Error

Pink crab with an alert badge. An API error occurred in this session.

Architecture

How it works

Claude Observer uses Claude Code's hook system to track session lifecycle events in real time.

1

Hook Events Fire

Claude Code triggers hooks on session lifecycle events: start, prompt submit, stop, error, and notification.

2

Python Hook Writes State

The observer hook script receives event data via stdin and writes/updates a JSON file per session to ~/.claude-observer/sessions/.

3

Swift App Polls

The status bar app polls the sessions directory every 2 seconds, reads the JSON files, and updates the menu bar display.

4

Notifications & Cleanup

When a session transitions to "needs input", a native macOS notification is sent. Dead sessions are automatically cleaned up.

Getting Started

Install in seconds

Requires macOS 12+, Xcode Command Line Tools, and Python 3.

1

Clone the repository

git clone https://github.com/svenliebig/claude-observer.git
cd claude-observer
2

Install

Compiles the Swift app, installs the hook script, and configures Claude Code hooks.

make install
3

Run

make run
# or directly:
~/.claude-observer/bin/claude-observer &

Stop

make stop

Uninstall

make uninstall

Tip: Add the binary to System Settings > General > Login Items for auto-start on login.
